## 3.3 ProjektDatei [IST]
Anhang an ein Projekt: name, pfad, kategorie (Plan/Zeichnung, Technik/Rider, Vertrag, Foto, Sonstiges),
beschreibung, groesse, hochgeladen, von. Liegt im Ordner <Projekt>/Dokumente/Dateien. Erlaubte Endungen:
pdf, png, jpg, jpeg, gif, webp, svg, txt, csv, doc, docx, xls, xlsx, ppt, pptx, odt, ods, zip, dwg, dxf, graphml, vwx,
skp, rtf. Maximal 50 MB je Datei.
