# 8. Oberflächen-Vorgaben
 • UI-1 Menü (Seitenmenü, nach Arbeitsablauf gruppiert, nur erlaubte Einträge sichtbar): Start (Übersicht,
   Suche) · Aufträge (Kunden, Projekte, Kalender, Aufgaben, Angebote, Planungszeit) · Material & Lager
   (Material, Geräte, Plan-Symbole, Ladezonen, Code scannen) · Kalkulation (Kalkulator, Zeitrechner) ·
   System (Verwaltung). Der aktive Eintrag wird nach längstem passenden Pfadpräfix markiert. Keine
   „Zuletzt angesehen"-Liste.
 • UI-2 Rückmeldung: Grün = erledigt, Gelb = erledigt mit Hinweis, Rot = nicht erledigt. Farbe nie allein:
   zusätzlich Text/Symbol.
 • UI-3 Scan-Bedienung: Fokus bleibt im Scan-Feld; Enter bucht; Ton/Vibration optional; große
   Touch-Flächen (mindestens 44 px) am Arbeitsplatz; Kamera-Dialog schließbar.
 • UI-4 Formulare: Pflichtfelder markiert, Fehler direkt am Feld, Speichern nur einmal (kein
   Doppelklick-Doppelbuchen). Sicherheitsabfrage bei Löschen/Verladen/Wiederherstellen.
 • UI-5 Texte: Deutsch, Du-Form, kein Fachjargon, Fehlertext = Ursache + nächster Schritt.
 • UI-6 Darstellung: Hell/Dunkel (Systemeinstellung), 8 Themen, 3 Dichten, Smartphone-tauglich
   (Arbeitsplätze und Kamera).
 • UI-7 Barrierefreiheit: Kontrast >= 4,5:1, Tastaturbedienung, Beschriftungen für Bedienelemente.
 • UI-8 Cache: Statische Dateien tragen eine Versionskennung ({% asset 'datei.js' %}), damit Änderungen
   sofort greifen.
