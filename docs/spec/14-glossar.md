# 14. Glossar
Begriff                     Bedeutung
Artikel                     Eine Sorte Material im Stamm (z. B. „XLR-Kabel 5 m")
Gerät                       Ein einzelnes Stück eines Artikels mit eigenem Code
Case / Tasche               Behälter mit definiertem Inhalt (z. B. 4 Lampen)
Job                         Kleiner Auftrag oder Teilbereich (Gewerk) eines Projekts
Packliste                   Liste dessen, was für ein Projekt mitgenommen wird, aus dem Angebot
Vormerkung                  Reservierung durch ein versendetes Angebot (zeitlich begrenzt)
Fest reserviert             Reservierung durch ein angenommenes Angebot
Ladezone                    Platz im Lager, an dem ein Projekt gepackt wird
Arbeitsplatz                Fest angemeldetes Lagergerät, das ein Mitarbeiter per Name/PIN entsperrt
Bewegung                    Eintrag im Lagerprotokoll zu einem Gerät
Level                       Ergebnisfarbe eines Scans: ok (grün), warn (gelb), error (rot)
Fassung                     Version eines Angebots
Mengenschritt               Mindest-Set-Größe bei der Vermietung (z. B. nur 4er-Sets)
